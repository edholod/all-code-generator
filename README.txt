Генератор кодов для GitHub Pages / Telegram WebApp. Откройте index.html через HTTPS. Распознавание с камеры и фотографии работает через html5-qrcode (CDN), требуется интернет. Для камеры браузер запрашивает разрешение. Фото обрабатывается локально. Поддержка отдельных форматов зависит от библиотеки.

Определение формата: при сканировании камерой используется информация декодера; для фотографии сначала BarcodeDetector (если поддерживается), затем резервный декодер. Если тип не сообщён, показывается «Не удалось определить автоматически».
